# moon_craters — Malapert Massif crater survey

Reproducible pipeline for lunar crater detection and size-frequency analysis
at Malapert Massif (~86 S).

**Current state: Phase 0 complete, blocked on network egress.**
Read `STATUS.md` first, then `PLAN.md`, `DECISIONS.md`,
`reports/environment_audit.md` and `reports/data_feasibility_malapert.md`.

Layout: `config/` `src/` `scripts/` `tests/` `notebooks/`
`data/manifests/` `reports/` `artifacts/`

No bulk imagery, credentials or model weights are committed to this
repository; they are tracked through manifests.
